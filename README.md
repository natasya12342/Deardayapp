# 📷 DearDay - "A little piece of my day, for you."

DearDay adalah aplikasi *social diary* sederhana yang dirancang khusus untuk berbagi potongan aktivitas sehari-hari dengan teman, pasangan, atau orang terdekat. Tidak ada *followers*, *likes*, atau algoritma pencarian sensasi—hanya Anda dan keseharian orang-orang yang Anda pedulikan.

## 🌟 Konsep Utama
Aplikasi ini berfokus pada intimasi digital. Pengguna mengunggah rentetan aktivitas mereka dalam bentuk "Moments" (Foto + Caption + Mood + Waktu) untuk menceritakan hari mereka kepada *Close Friends*.

## 🛠 Teknologi (Frontend MVP)
Versi repositori ini adalah MVP statis yang dirancang untuk dieksekusi di *browser* atau GitHub Pages:
- **HTML5** (Semantik dan struktur UI)
- **CSS3** (Variabel CSS, Animasi, Flexbox, Desain *Mobile-First*)
- **Vanilla JavaScript** (DOM Manipulation, State Management, FileReader API untuk simulasi unggah foto).

## 🚀 Cara Menjalankan
1. Ekstrak file .zip ini.
2. Buka folder `dearday-app`.
3. Buka file `index.html` menggunakan *browser* (Chrome/Safari/Firefox).
4. Klik **"Sign In"** (sistem menggunakan otentikasi simulasi untuk demo).
5. Coba tambahkan foto baru dengan menekan tombol `+` di navigasi bawah!

> *Catatan: Karena ini adalah aplikasi frontend statis (tanpa backend/database), momen baru yang Anda tambahkan akan hilang saat halaman direfresh.*
